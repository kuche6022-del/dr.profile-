# Dr. Grace Obar — British Professional Website

A responsive, multi-page static website with a UK editorial design direction, British English copy, and a distinct colour palette for each programme.

## Deploy on Render
Create a **Static Site** connected to the GitHub repository containing these extracted files.
- Root Directory: leave blank
- Build Command: leave blank
- Publish Directory: `.`

## Important before launch
1. Add Grace's approved professional photographs and replace the abstract visual on the home page if desired.
2. Add a real booking-calendar URL and professional email address.
3. The contact form is currently a front-end placeholder; connect it to a secure form provider before collecting enquiries.
4. The privacy, cookie, terms and accessibility pages are starter drafts and need review against the actual business, services, tools and legal obligations.
5. Confirm qualifications, dates, professional roles, DBS and insurance claims, safeguarding arrangements, supervision and service scope with Grace before publication. Items flagged as pending in the supplied brief have not been represented as verified.
6. Confirm the current business location and whether in-person sessions are available in Croydon.
7. Add real testimonials only with written consent. No testimonials have been invented.
